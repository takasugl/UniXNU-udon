### `rd=md0` incorrectly changed root selection

The first `data-ramdisk-005` attempt stopped before launchd:

```text

```

The Data configuration did not alter the cache code. The mistake was adding `rd=md0` alongside
the real UFS OS root. `rd=md0` can make the initrd/memory disk the root device; the owner
SystemOS carrier then correctly rejected the unexpected root/device composition.

The previously qualified offline combination distinguishes the two cases:

